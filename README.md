# Interpretive Sculpture Pattern — VR / Web Quest

> Διαδραστικό VR γλυπτό για την ενότητα «Μέγας Βασίλειος» (Β2).  
> Οι μαθητές ανακαλύπτουν μια κρυμμένη επιγραφή, ξεκλειδώνουν τη «Βασιλειάδα» και φωτίζουν το γλυπτό με συνεισφορές που τεκμηριώνονται με πηγές.

---

## 1. Πώς λειτουργεί η εφαρμογή

### Βασική ιδέα

Το γλυπτό αποτελείται από **6 περιοχές**. Κάθε περιοχή αντιστοιχεί σε έναν διαφορετικό τύπο συνεισφοράς και ανάβει με διαφορετικό χρώμα όταν μια τάξη ή ομάδα προσθέτει ιδέα με τεκμηρίωση.

Η ροή του παιχνιδιού είναι ένα τρισδιάστατο **quest**:

1. **Φάση 1 — Το Σκοτάδι:** Τα Χέρια (Arms) ξεκινούν εντελώς σβηστά.
2. **Φάση 2 — Η Αναζήτηση:** Ο μαθητής περιστρέφει τη σκηνή / κινείται στο VR και βρίσκει την κρυμμένη επιγραφή «Ζήτησε τη Βασιλειάδα» πίσω από το γλυπτό.
3. **Φάση 3 — Η Αποκάλυψη:** Κάνοντας click / πλησιάζοντας την επιγραφή, εμφανίζεται πληροφοριακό πάνελ για τη φιλανθρωπία του Μεγάλου Βασιλείου και τα Χέρια ανάβουν με πράσινο χρώμα (Ηθική / Κοινωνική προσφορά).

Από εκεί και πέρα, οι μαθητές μπορούν να επιλέγουν περιοχές, να υποβάλλουν συνεισφορές με πηγή και να βλέπουν το γλυπτό να **φωτίζεται δυναμικά**.

---

## 2. Οι περιοχές του γλυπτού

| Περιοχή | Ελληνική ονομασία | Σημασία | Default χρώμα |
|---------|-------------------|---------|---------------|
| `base` | Βάση | Τα θεμέλια της έννοιας | Καφέ / γήινο |
| `trunk` | Κορμός | Το κύριο σώμα δεδομένων | Καφέ |
| `arms` | Χέρια | Η δράση και η εφαρμογή | Γκριζοπράσινο |
| `head` | Κεφαλή | Το ανώτερο νόημα / Θεολογία | Γκριζοκίτρινο |
| `periphery` | Περιφέρεια | Το ιστορικό πλαίσιο | Γκριζομπλέ |
| `core` | Εσωτ. Πυρήνας | Η ουσία και η κινητήριος δύναμη | Πορτοκαλί φως |

### Χρώματα κατηγοριών

Όταν μια περιοχή πάρει συνεισφορά, το χρώμα της αλλάζει ανάλογα με την **κατηγορία** της ιδέας:

| Κατηγορία | Χρώμα | Έννοια |
|-----------|-------|--------|
| `theological` | `#8866ff` (μωβ) | Θεολογική διάσταση |
| `ethical` | `#66ff88` (πράσινο) | Ηθική / κοινωνική προσφορά |
| `historical` | `#ffaa44` (πορτοκαλί) | Ιστορικό πλαίσιο |
| `philosophical` | `#44aaff` (μπλε) | Φιλοσοφική ανάλυση |

Όσο περισσότερες συνεισφορές και τεκμηρίωση συγκεντρώνει μια περιοχή, τόσο μεγαλύτερη η ένταση του φωτός (`emissiveIntensity`).

## 3. Ροή δεδομένων — από το Google Sheet στο VR

```text
Google Sheet (μαθητές γράφουν)
    ↓
Google Apps Script τρέχει συγχρονισμό
    ↓
Push στο αρχείο public/contributions.json σε αυτό το repo
    ↓
GitHub Pages / Lovable ανανεώνει το site
    ↓
Η εφαρμογή φορτώνει /contributions.json κάθε 30 δευτερόλεπτα
    ↓
Τα σημεία του γλυπτού που αναφέρονται στο JSON ανάβουν στο VR headset
```

### Το αρχείο `public/contributions.json`

Αυτό είναι το κοινόχρηστο αρχείο «συλλογικής μνήμης». Οι μαθητές δεν το αγγίζουν χειροκίνητα — ενημερώνεται αυτόματα από το Sheet. Αν θέλεις να το φορτώσεις χειροκίνητα για προετοιμασία, δες παρακάτω «Προκατασκευασμένα σενάρια JSON».

## 4. Έλεγχοι

### Web (ποντίκι / πληκτρολόγιο)

| Ενέργεια | Τρόπος |
|----------|--------|
| Περιστροφή | Drag με ποντίκι |
| Zoom | Scroll wheel |
| Επιλογή περιοχής | Click πάνω στο τμήμα του γλυπτού |
| Auto-rotate | Πλήκτρο `Space` |
| Διαγραφή 3D asset | Επιλογή asset + πλήκτρο `Del` |

### VR (Meta Quest / WebXR)

| Ενέργεια | Τρόπος |
|----------|--------|
| Είσοδος VR | Κουμπί «ΕΙΣΟΔΟΣ ΣΕ VR» |
| Κίνηση εμπρός/πίσω/πλάγια | **Αριστερό thumbstick** |
| Στροφή (snap 30°) | **Δεξί thumbstick** αριστερά/δεξιά |
| Teleportation | Κράτημα **Grip** (squeeze) οποιουδήποτε χεριού → εμφανίζεται τροχιά → άφημα για μεταφορά |
| Επιλογή περιοχής / asset | Trigger (select) με το δεξιό χέρι |
| Wrist UI | Εμφανίζεται στο αριστερό χέρι — επιλογή κατηγορίας/περιοχής και υποβολή |

## 5. Προκατασκευασμένα σενάρια JSON (προπαρασκευαστικό)

Εκτός από το ζωντανό Google Sheet, μπορείς να **φορτώσεις ένα προετοιμασμένο αρχείο JSON** στην εφαρμογή για να «επαναφέρεις» μια προηγούμενη τάξη ή για να προετοιμάσεις τη συζήτηση πριν μπουν οι μαθητές στο VR.

### Βήματα για δημιουργία σεναρίου

1. **Άνοιξε το πάνελ «JSON»** στην εφαρμογή (κουμπί `📋 JSON` πάνω δεξιά).
2. **Πάτησε «ΕΞΑΓΩΓΗ»** για να δεις το τρέχον template.
3. **Αντέγραψε το πεδίο `contributions`** ή ξεκίνα από το παράδειγμα παρακάτω.
4. **Τροποποίησε τα κείμενα και τις πηγές** με δικές σου πηγές (π.χ. από τον Μέγα Βασίλειο, Γρηγόριο Ναζιανζηνό, κ.ά.).
5. **Αποθήκευσε** τοπικά με «ΑΠΟΘΗΚΕΥΣΗ» ή με δικό σου editor.
6. **Φόρτωσέ το** στην εφαρμογή με «ΦΟΡΤΩΣΗ ΑΡΧΕΙΟΥ» ή κάνε paste στον editor και πάτα «ΕΙΣΑΓΩΓΗ».

### Μορφή κάθε συνεισφοράς

```json
{
  "region": "head",
  "text": "Η Θεολογία ως επιστήμη του Θεού",
  "source": "Μέγας Βασίλειος, Εἰς τὸ Ἅγιον Βάπτισμα",
  "category": "theological"
}
```

| Πεδίο | Τύπος | Απαιτείται | Περιγραφή |
|-------|-------|------------|-----------|
| `region` | string | Ναι | Μία από: `base`, `trunk`, `arms`, `head`, `periphery`, `core` |
| `text` | string | Ναι | Η ιδέα / σύντομη διατύπωση |
| `source` | string | Προαιρετικό | Τεκμηρίωση / απόσπασμα. Αν είναι > 5 χαρακτήρες, θεωρείται «ισχυρή τεκμηρίωση» και δημιουργείται 3D επιγραφή |
| `category` | string | Προαιρετικό | Μία από: `theological`, `ethical`, `historical`, `philosophical`. Default: `theological` |
| `id` | string/number | Προαιρετικό | Μοναδικό αναγνωριστικό. Αν λείπει, δημιουργείται αυτόματα |
| `timestamp` | string | Προαιρετικό | Ημερομηνία ISO. Αν λείπει, μπαίνει τωρινή |
| `docScore` | number | Προαιρετικό | Βαθμός τεκμηρίωσης (1–10). Αν λείπει, υπολογίζεται από το μήκος της πηγής |

### Πλήρες παράδειγμα σεναρίου

```json
{
  "template": {
    "version": "1.0",
    "regions": ["base", "trunk", "arms", "head", "periphery", "core"]
  },
  "instance": {
    "class": "B2",
    "subject": "Μέγας Βασίλειος",
    "year": 2026
  },
  "contributions": [
    {
      "id": "prep-1",
      "region": "head",
      "text": "Η Θεολογία ως επιστήμη του Θεού",
      "source": "Μέγας Βασίλειος, Εἰς τὸ Ἅγιον Βάπτισμα",
      "category": "theological",
      "timestamp": "2026-08-23T10:00:00Z"
    },
    {
      "id": "prep-2",
      "region": "base",
      "text": "Η παιδεία ως θεμέλιο κάθε αρετής",
      "source": "Μέγας Βασίλειος, Πρὸς τοὺς Νέους",
      "category": "ethical",
      "timestamp": "2026-08-23T10:00:00Z"
    },
    {
      "id": "prep-3",
      "region": "arms",
      "text": "Η Βασιλειάδα — έμπρακτη φιλανθρωπία",
      "source": "Γρηγόριος Θεολόγος, Ἐπιτάφιος εἰς Μέγαν Βασίλειον",
      "category": "ethical",
      "timestamp": "2026-08-23T10:00:00Z"
    },
    {
      "id": "prep-4",
      "region": "periphery",
      "text": "Καισάρεια του 4ου αιώνα — κέντρο παιδείας και εκκλησιαστικής ζωής",
      "source": "",
      "category": "historical",
      "timestamp": "2026-08-23T10:00:00Z"
    }
  ]
}
```

> **Σημείωση:** Η εφαρμογή αποδέχεται και μόνο τον πίνακα `contributions` ως JSON (π.χ. `[{...}, {...}]`). Τα πεδία `template` και `instance` είναι προαιρετικά metadata.

## 7. Χρήσιμες ρυθμίσεις για προετοιμασία

### Για προβολή σε VR headset (Meta Quest)

- Άνοιξε το published URL ή το preview URL στο **Meta Quest Browser**.
- Πάτησε «ΕΙΣΟΔΟΣ ΣΕ VR».
- Ο χρήστης ξεκινά σε απόσταση ασφαλείας (z ≈ 10m) για να μην εμφανιστεί μέσα στο γλυπτό.

### Για προετοιμασία πριν το μάθημα

1. Δημιούργησε ένα JSON με τις πηγές που θες να φωτίσεις.
2. Φόρτωσέ το στην εφαρμογή μέσω του πάνελ JSON.
3. Ρύθμισε το κάθε περιοχή με κατάλληλη κατηγορία και πηγή.
4. Πάτησε «ΕΠΑΝΑΦΟΡΑ DISCOVERY» για να επανέλθεις στη συλλογική μνήμη όποτε θες.

## 9. Συμβουλές για τη σάλπιγγα τάξης

- **Ξεκίνα με το quest:** Άφησε τα Χέρια σβηστά μέχρι οι μαθητές να βρουν την επιγραφή.
- **Χρησιμοποίησε το JSON για προετοιμασία:** Φόρτωσε 3–4 προεπιλεγμένες συνεισφορές πριν μπει η τάξη στο VR, ώστε να έχεις ένα «ζωντανό» γλυπτό από την αρχή.
- **Ζωντανή συλλογική μνήμη:** Κατά τη διάρκεια του μαθήματος, οι μαθητές γράφουν στο Sheet και το γλυπτό ανανεώνεται αυτόματα (κάθε 30").
- **Επαναφορά:** Μετά από κάθε δοκιμή ή πειραματισμό, το κουμπί «ΕΠΑΝΑΦΟΡΑ DISCOVERY» επαναφέρει την καθαρή κατάσταση από το GitHub.
