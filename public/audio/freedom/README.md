# Freedom lesson audio

These are the 12 mono 48 kHz PCM WAV voice clips from the `eleftheria-kai-dogmatiki-syneidisi` lesson. The Ready Player Me pilot uses three of them as first-light rewards:

- `eleftheria_inner_final.wav` → `head`
- `eleftheria_inner_01_bondage.wav` → `trunk`
- `eleftheria_social_final.wav` → `arms`

The remaining clips stay available for later lesson JSON authoring. The stereo `eleftheria_ambient_theme.wav` is not included in this first browser pilot; it can be added later as an explicit, user-started lesson background.
